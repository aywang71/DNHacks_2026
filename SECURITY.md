# Security policy

This is an archived hackathon prototype and no longer receives active security
maintenance. Do not submit credentials, tokens, personal data, or private
source material in public issues, pull requests, or forks.

If you believe a currently exposed credential or sensitive data requires
removal, contact the repository owner privately through GitHub rather than
disclosing details in the repository. Rotating the affected credential is the
first response; removing it from current files does not remove it from Git
history.
